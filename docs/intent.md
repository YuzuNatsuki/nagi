# Intent: 凪（nagi）

## プロダクトの目的

「察する」を、AIで取り戻すこと。

大切な人の専属の小さな分身となるAIエージェントが、その人の機微を観察し、もう一方のスマホで動いて受け手にそっと伝える。日本的な「察しの文化」を技術で実装する。

## 解決する課題

日本には「言わなくてもわかってほしい」という察しの文化がある。しかし現代は皆忙しく、相手の機微を見逃してしまう。すれ違いが積み重なり、近くにいる人ほど遠くなる。

特に深刻な3つの関係：

- 共働き夫婦：会話が減り、相手の状態がわからない
- 父と思春期の子：日本社会の典型的断絶
- 同棲・遠距離カップル：すれ違いが小さな喧嘩を生む

既存のコミュニケーションアプリは「もっと話そう」を促すが、現代人の課題は「察する力の不足」にある。

## 革新性

世のAIアプリは「AIに話しかけるアプリ」（AI彼女、AIチャット相手など）。これらは人間関係の代替物として設計されている。

凪はその逆：

> AIに話しかけるアプリは、たくさんある。
> 凪は、AIが、あなたに、大切な人について、話しかけるアプリ。

凪は人間関係の触媒として動く。AIが関係の代わりではなく、人間同士の関係を深めるための媒介になる。

## 想定ユーザー

主要ターゲット（広めの設定）：

1. 共働き夫婦（推定2,000万人）
2. 父と思春期の子（推定数百万人）
3. 同棲・遠距離カップル（推定数百万人）

デモでは父娘と夫婦の両方を見せる。

## 提供する価値

1. 大切な人の機微に気づく機会を増やす
2. すれ違いを未然に減らす
3. 行動の選択肢は人間に残す（AI支配感がない）
4. 沈黙を贈り物にする（通知頻度を抑える）
5. 数値化・可視化しないので、関係性をスコア化する不快感がない
